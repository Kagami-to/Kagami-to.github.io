# 鏡外 英語翻訳リファレンス

> YAML / CSV のデータを記述・翻訳する際に参照する制作資料。
> このファイルはGitHub Pagesの実行時データとしては使用せず、翻訳時の表記統一を目的とする。

## 基本方針

- Characters / Works / Songs の名前そのものは、それぞれのCSVを一次データとする。
- 本リファレンスには、各CSV/YAMLをまたいで再利用される固有語、名称構成要素、固定訳、翻訳上の注意を記録する。
- 既存の英語表記がある場合でも、本リファレンスで確定していないものは自動的に正式訳とはみなさない。
- 文脈によって英訳が変わる語は、文脈を明記する。

## 文脈によって表記が変わる語

### 天照宮

「天照宮」は文脈によって英訳を区別する。

- 施設名・組織名 → **Tenshōgū**
- 人名 → **Amaterumiya**

したがって、単純な文字列置換で一律に `Tenshōgū` としてはならない。

## 今後追加する項目

以下のような情報が新たに登場した場合は、本リファレンスへの追加を検討する。

- 世界観固有の用語
- 組織・施設・地名などの固定訳
- 人物名や作品名を構成する名称要素
- 固有の役職・制度・宗教用語
- 一般的な訳語とは異なる公式訳
- 文脈によって訳し分ける必要がある語
- 表記揺れを防ぐための翻訳規則
