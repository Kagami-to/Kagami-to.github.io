# KAGAMITO 公式サイト用ページデータ

このフォルダは、Framerで構築するKAGAMITO公式サイトのページ構成・掲載内容を管理するためのデータ置き場です。

## 方針

- サイトの掲載内容と構成をGitHubで管理する
- Framer側のデザインと、GitHub側のコンテンツを分離する
- まだ確定していない内容は無理に埋めず、下書きとして管理する
- 画像・動画などの大容量ファイルは、必要に応じて別途管理する

## ページ構成

- `index.md` — トップページ
- `game.md` — ゲーム概要
- `characters.md` — キャラクター
- `world.md` — 世界観・設定
- `works.md` — 登場作品・関連作品
- `news.md` — お知らせ・更新情報
- `downloads.md` — ダウンロード・配布物
- `contact.md` — 連絡先・リンク

## 補足

このフォルダでは、まず「何を掲載するか」を管理します。
Framer上でのレイアウト、アニメーション、レスポンシブ対応などのデザイン実装とは分離して管理します。
